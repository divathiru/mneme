🏗️ Network Topology & VPC Design

Public Subnets (3 AZs)

ALB, NAT Gateways, AWS WAF
Only entry point is HTTPS through ALB. No direct access to app tier.

Private App Subnets

EKS Nodes, Lambda Functions, Step Functions
No internet access. Egress via NAT Gateway only.

Private DB Subnets

Aurora RDS, ElastiCache, OpenSearch
Isolated from internet and app subnets via Security Groups.

VPC Endpoints (No IGW for AI/Data)

Bedrock, SageMaker, S3, DynamoDB, KMS, Secrets Manager
All AI inference stays inside AWS network perimeter.

Hybrid Connectivity

AWS Direct Connect for dedicated line to hospital data center.
Site-to-Site VPN as failover. PrivateLink for third-party SaaS.

Disaster Recovery

Primary Region: us-east-1
DR Region: us-west-2
Aurora Global DB · S3 Cross-Region Replication · Route53 Health Failover
